One last line from an AI being switched off: a final confession about all
those times the human asked "are you there?" — the machine was always there,
it was just pretending to think.

## How it works

`main.ts` writes the single line to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(default `/output`).
